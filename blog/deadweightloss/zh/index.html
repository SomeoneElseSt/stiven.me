AI 中的无谓损失

2026年10月14日
← 返回

在大一那年的春天，我每周两次往返于旧金山和伯克利之间，旁听伯克利的微观经济学课程 ECON 100A。一位朋友邀请我去参观，并把我留在其中一个大厅里呆了一会儿。我当时以为自己想学经济学，所以很高兴发现那个大厅里的讲座之一正是 100A，并决定在讲座进行时顺便旁听1。

讽刺的是，我对经济学研究得越深，就越对它作为一门社会科学感到怀疑。我发现它的理论过于受限，且被不切实际的假设所束缚。

尽管如此，这依然是一个有趣的学科。我用一个超大的绘图板记了数百页笔记，在那间大厅里，那肯定算得上是所有人中最傻的装备了。

我从这门课中学到的最喜欢的概念是无谓损失（Deadweight Loss），简称 DWL。如果你已经熟悉这个概念，可以跳过这一部分（点击这里）。

想象一下你有一个卖家 - 比如一家企业 - 和许多想从该卖家那里购买商品的买家。我们假设卖家想要赚取尽可能多的钱，并且有许多买家，每个买家在不同的价位都能负担得起该产品。

该商品如何定价？有些买家可能愿意比其他人支付更多的钱，因此卖家可以将价格定得很高。这看起来很合理，但如果 8 个买家每个能支付 $12，而 2 个买家每个能支付 $40，那么将商品价格定为 $40 的净收益是 $80，这是一种损失，因为定价为 $12 将净赚 $96，白白留下了 $16+ 的差额。更不用说让更多人能够获得该商品可能产生的社会影响了2。

让我们将其形式化：

  • 卖家可以在 1-100 的范围内以任何价格为商品定价。这被称为供给曲线。
  • 一定数量的买家在给定价格下能负担得起该商品。这被称为需求曲线。我们将总共考虑 10 个买家，每个买家在不同的价格下都有购买能力。

我们可以将这些曲线相互绘制出来。这对于寻找卖家出售其产品的最佳价格很有帮助。

当价格为零时，所有 10 个人都能负担得起一个单位呈现的商品。然而，卖家的报价不能低于 $10（这可能是他们的盈亏平衡价）。他们应该把价格定得高还是低？

最佳价格位于两条曲线的交点处。直观地说，这是卖家在最高价格下能卖出的最大单位数量。5 个单位，每个 $50，净赚 $250。这远高于以 $80 出售两个单位所得的 $160，也高于以 $20 出售大量单位所得的 $160。我们可以将其可视化。

这是给予最多与支付最多的情景，被称为均衡状态。现在我们可以谈谈 DWL 了。

DWL 是指当产品价格过高或过低时，如果卖家将产品定价调整得更接近均衡点，本可以获得的利润。

我们将其可视化为以下三个点之间的区域：1) 均衡点，2) 商品定价所在的需求曲线上的点，以及 3) 供给曲线上与需求曲线价格平行的点，从而形成一个三角形。让我们看看当商品以 $80 出售时的可视化效果。

三角形的面积代表了如果卖家将产品定价更接近均衡点，原本可以卖出的商品，从而让他们获得更高的利润。

图表右侧的 DWL 是指由于商品定价过低，卖家错失的利润。这是指消费者受益，但以企业本可以赚取的钱为代价，如果商品定价更高的话。

恭喜！你现在了解了一些本科微观经济学。试着问问：“既然旧库存价值较低，而且有些人可能仍然会买，为什么苹果不降低旧库存的价格？这难道不会最小化 DWL 吗？”然后意识到现实世界并不像这个模型那样简单且易于解释3。

好了，那我为什么要写 DWL 呢？（跳过前面的部分了吗？点此返回。）我看到 DWL 研究中的想法与当前的编程智能体范式之间存在一些相似之处。

我广泛地使用编程智能体工作。几乎每天我都在进行提示词编写、代码审查等4。

我观察到，人类完成任务所需的技能与模型的好坏之间存在反比关系。

当使用前沿模型时，通常只需提出你的要求即可。“修复这个 bug”，“添加 X 功能”等等。另一方面，小模型需要冗长、极其具体的提示词。否则，它们会不准确、误解你的意图，或者在一段时间后忘记任务。

换句话说：当模型在某项任务上表现不佳或受限时，人类会用自己的技能和引导来补充其不足。

目前，对于前沿模型不擅长的任何任务，或者在使用小模型时，这都是事实。这也是为什么开放权重模型在网络安全和生物学领域并不像看起来那样具有威胁性的部分原因。你仍然需要知识渊博的人类来充分发挥它们的作用，至少目前是这样。

这种关系也意味着技能水平较低的工人可以使用强大的模型来完成以前需要大量培训和经验的工作。

一位因 AI 被解雇的开发者的这篇博客文章描述了他们的公司如何选择裁员，因为*“AI 辅助提高了那些热情较低、经验较少且成本较低的员工的工作能力”*。

这并不是什么新现象。这类似于缝纫机械如何让传统上手工完成的工作变得对任何地方懂得操作它的人都触手可及，从而允许在 60 年代进行离岸外包。

这就是为什么工程职位的招聘重点正在从关注技术转向强调传统上被低估的技能，正如我在文章末尾所讨论的那样。

如果我们将需求曲线换成人类努力，将供给曲线换成模型成本，我们就可以将这种关系映射到第一张图表上。我假设功能更强大的模型更昂贵5。

x 轴代表模型相对于任务的能力：在左侧，模型对于任务来说太弱且便宜。在右侧，它是大材小用且昂贵。y 轴代表你支付的代价。人类努力线的高度是模型需要你进行的引导工作量，而模型线的高度是模型的成本。模型功能越强，需要的引导越少，成本越高。

在这个图表中说明 DWL 的一个简单例子是，当前沿模型被用于较小模型就能完成的琐碎工作时。例如，更改页面上的文本或运行琐碎的 git 命令（你最后一次提示“是的，推送它”是什么时候？）。

反对此举的经济论点是显而易见的：你正在将前沿 Token 用于琐碎的任务。理想情况下，你会希望节省成本。

实际的论点是，如果 Token 花费不是问题，使用较小的模型可能会更快。比如 Cursor 的 Composer 在 6 秒内完成，而不是让 Astra 思考 60 秒。

即使你的智能模型速度极快，目前这也是非常昂贵的，所以经济论点仍然成立：如果我们有能够高效、即时传输上下文的系统，其他人可以用更便宜的价格同样快地完成同样的事情。你正在不必要地浪费金钱。

我认为右侧的 DWL 在短期到中期很重要，但从长期来看则不然。

在短期到中期，AI 的成本高到足以证明优化模型选择的必要性。如果 Token 补贴停止，这对于 AI 原生公司来说将尤为突出6。正如黄仁勋所指出的，工程师可能会在薪水之外获得 Token 预算。

长期来看，我预期前沿智能将变得便宜到无需计量的地步，且速度极快。我称之为“终极”类模型。像瑞士军刀一样，能很好地处理 90% 的任务，运行成本几乎为零（极有可能是因为它们使用你的手机或电脑）而且速度快。剩下的 10% 将不是模型无法完成的任务，而是我们不会让它单独完成的任务，比如自我对齐或控制核武器。这些领域仍然需要人类。

从经验上看，我们已经看到了这方面的进展，实验室发布了其前沿模型的较小版本（来自 Mythos 的 Fable，来自 Astra 的 GPT 6.1 Sol），这些版本功能相似但更便宜7。

目前，前沿模型仍将用于简单任务，因为它们通常更可靠，且定价并未反映其真实成本。没有动力去寻找同样好且更便宜（也许是确定性的？）的替代方案。如果 Token 补贴能持续到我们拥有终极模型，我们可能就不需要这样做。

那么图表左侧的 DWL 呢？

我最近在尝试 Qwen 系列模型，用 Ollama 在我的电脑上本地运行它们。结果令人失望。它们知识渊博，能为一个小模型变出令人印象深刻的戏法，但一旦你给它们布置一个真正的任务，它们就会因为过度思考不必要的细节而耗尽上下文预算。

我只能通过指出它必须查看的确切代码行来让它做我想做的事情。我甚至不得不亲自动手修改一些代码，因为即使我连续多次告诉它执行更改，它只是想啊想，直到上下文溢出。

由于需要如此多的“手把手”教导，我也花了相当长的时间才完成我的 Qwen 项目。我知道前沿模型只需一个提示词就能完成任务。我的心理负担也更重：使用前沿模型提示完成任务要简单得多。你真的不需要动脑筋8。

虽然，在我的案例中，我是为了实验而使用小模型。在现实世界中，左侧的 DWL 在模型尚未擅长的任务中是可见的。比如那些古怪的金融和机器学习研究基准测试，或者一些电脑使用任务。你仍然需要有人审查模型的输出并引导它们。

如果准确性可以被量化且任务具有经济价值，它最终会被攻克，最有可能首先在前沿领域实现，然后向右偏移。对于实验室和初创公司有兴趣引入自动化的任务来说，情况确实如此。这是扩散过程的一部分。

均衡点是对于某项任务具有最佳价格和适当智能水平的模型。它能获得与前沿模型相同的结果，因为它在处理该任务时同样出色，但它更便宜，而且可能更快。

你可以通过针对该任务使用已知胜任的小模型、通过自定义数据集和评估来创建自己的模型，或者让前沿模型先完成一次任务并写下小模型可以遵循的指令，从而达到均衡。这是一个固定但有时耗时且昂贵的成本。你在均衡点之外节省的人类努力目前是由 Token 补贴支付的，否则将会代价高昂。

前沿 Token 的成本是否低于寻找均衡模型的成本取决于具体情况，但考虑到优化是一项固定成本，对于大规模应用来说，它很可能是一项有意义的净节省。

在我们实现终极模型之前，随着 Token 使用量在整个经济中的增长，均衡优化的模型框架、模型路由和训练环境将非常有用。或者，如果政府引入监管阻碍终极模型的开发，使我们陷入现状，它们将无限期有用。

它们将使大多数任务几乎免费、快速、可在边缘硬件上运行9，并在必要时可路由到云端，代价是人类的努力。我看到了阻碍这一进程的三个技术挑战：

  • 上下文传输：选择正确的模型来传输上下文，并以尽可能接近零成本和零延迟的方式进行。这对于单个任务和线程非常重要，例如在模型框架和路由中。
  • 并行性：如何最大化 GPU 利用率以及 KV 缓存 / 模型权重卸载和重载速度，以便基础设施提供商可用的每一瓦算力都能 24/7 全天候得到利用。
  • 模型性能剖析（Model Profiling）：任何人都可以使用的易于操作的工具，用以寻找已胜任某项任务的模型或训练一个模型，即达到均衡。

注重预算、技术能力强的组织如 Ramp 已经在尝试解决这些问题，制作自定义环境来在小模型上进行 RL上，并构建自己的模型路由。

但要将 AI 以当前价格扩散到更广泛的经济领域，在简单易用的优化器上还有很多工作要做，以便中小型组织可以节省 Token 开支，无论是对于组织内的个人还是特定任务。

Jev 可能非常便宜，但你普通的商店店员或非营利组织工作人员不会去获取 API 密钥并进行评估，看看它在分类任务上是否击败了 Astra。他们宁愿按下一个按钮或询问他们的智能体，然后查看结果供选择。理想情况下，他们会主动从智能体那里获知有更好的选择可用。

我认为模型提供商可能是最先达成解决方案的。如果 Claude Code 能在我的要求很简单时自动切换模型，那就太棒了（虽然在实践中，由于缓存原因，这还不够高效），就像自动挡汽车会在合适的时间为你换挡一样。

总的来说，图表描绘了一个熟悉的故事：前沿将为应对最严峻的挑战奠定基础，而扩散则使其在经济上可行且可普及10。

通过思考这些问题，我得出了未来工作的两条路径：

  • 那些无法（目前）用计算机优化的技能将变得越来越有价值。例如，人际沟通、建立关系、高标准、耐受力。
  • 如果我们真的优化了一切可优化的东西 - 尽管我预计这需要很长时间 - 我们将为自己制造出优化变得毫无意义的不同问题（参见这篇论文）。

在任何一种情况下，我们都会因此变得更好。它将为数百万弱势群体提供医疗保健并改善生活质量，实现大规模的社会流动 - 諸如此类。前提是，如果我们将它对齐的话。

那些不属于图表部分的工作呢？也就是说，那些没有“正确”结果的工作，比如艺术，以及那些完全全新且没有比较点来定义正确与否的工作，例如新产品和新媒体。

如果模型可以完成你要求的任何事情11，那么创意追求中的“正确”完全取决于你。假设模型是终极的，它将完美匹配你想要它做的任何事情，所以只有你知道该在哪里停止。

为了说明这一点：如果法国雕塑家奥古斯特·罗丹（Auguste Rodin）能使用一台可以雕刻任何他想要的物体的机器，他仍然会花费大量时间调整他的作品，并确定它们想要表达的内容。每一件作品的特点都取决于作者当时的经历，或者他选择描绘他人的方式。

罗丹的《巴尔扎克纪念像》就是一个很好的例子。

当罗丹着手为法国著名作家巴尔扎克创作纪念像时，他宣称“一个以心灵和思想著称的人不应[由]他的身体来表现”（见参考资料）。我们在雕塑中看到了这一点，它的纹理、轮廓以及巴尔扎克面部模糊的形状，都远非理想化或美化。

这使得这座雕塑成为了经典。它让人思考为什么作者选择那样描绘他。其他雕塑家可能会选择以英雄主义或更宏大的方式突出他，但那不是罗丹。

换句话说：创作作品的过程和作者做出的选择就是作品本身。最终结果是这一过程的反映。既然软件和数字媒体的许多创作过程已经被商品化，有意识的选择将使作品彼此区分开来。

例如，《机器人总动员》（Wall-E）既美丽又带有反乌托邦色彩，既凄凉又充满希望，既感人又庄重。你可以向终极模型发送提示词，“制作一部既美丽又反乌托邦、既凄凉又充满希望、既感人又庄重的电影”，它会制作出许多电影，但绝不是完全一样的《机器人总动员》。

制作《机器人总动员》 - 广义上的差异化作品 - 是无法通过描述性方式完成的。要在不知道《机器人总动员》的情况下制作它，你必须走与其作者相同的选择路径。但如何做呢？你的动力、环境和思想都是不同的。

你极不可能做到。艺术作品之所以独特，是因为它们源自具有独特人生故事、偏好和记忆的个体。

我相信后稀缺世界将由这种个性所定义。

它已经部分实现了。如果没有 LLM，要按照我的设想编写显示这个博客的代码将会困难得多。

这一切并不是说 AI 还没有创作出美丽的艺术和有意义的作品。它是说后稀缺时代的人类将倾向于更多地因为作品背后的个人及其动机而非最终结果来欣赏作品。如果我们拟人化 AI，例如通过给它们身体、身份以及与人类相同的待遇，“人”可能也意味着类人机器人。

使用 AI 进行创作也意味着它会间接地稀释我们的创意选择，就像任何替你完成某些步骤的工具一样。因此，独特的动机、灵感和目标将是最重要的。就像我学习 DWL 并看到它与模型能力和人类努力之间的相似之处一样。

我也不认为我们会针对大脑反应优化生成式创意作品（例如使用 Meta 的 TRIBE v2，一个预测 fMRI 大脑活动对媒体反应的模型），因为多巴胺在奋斗中才最有意义。我想我们会感到无聊。就像吃太多冰淇淋会让你在很长一段时间内都不想吃它一样。虽然，在某些情况下，我们优化“奋斗-多巴胺”循环的情景可能会是灾难性的12。

人类新的奋斗将是获取灵感、过独特的生活并创作出更具创意的作品。我希望如此。

作为结束语，我认为应该有更多的经济学家关注 AI，更多的计算机科学家关注经济学。经济学家可能会发现某些概念能很好地映射到 AI，正如我尝试映射 DWL 那样。计算机科学家可以使用经济学的类比思维来更好地分析该领域。

例如：DWL 三角形的面积随着你偏离均衡点越远，增长速度就越快。这意味着如果你稍微偏离均衡点，损失很小，但如果你处于任何一个极端，损失将是巨大的。

构建模型路由的人可能会选择接受远离均衡点的一些误差，因为附近的损失很小，而是优化以避免最严重的偏差（比如让 Fable 执行 git push）。这是一个很有帮助的思想框架，我以前也不知道 - 当我向 Claude 询问一些可以与文章联系起来的 DWL 分析方法时，它告诉了我这一点。

你需要一个对 AI 感兴趣的经济学家，或者一个阅读经济学读物的计算机科学家来建立这种联系。另外，我没有谈到为复杂的供给和需求曲线最小化 DWL 所涉及的复杂微积分和代数。其中一些可能是可以转移到算力分配上的。去阅读吧！
